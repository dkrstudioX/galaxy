# Примеры дизайна ангара

Здесь лежат самостоятельные статические макеты. Они показывают варианты
интерфейса, но **не входят в рабочий ангар**:

- не собираются `py build.py`;
- не подключают `hangar.js` и `data/store.js`;
- не меняют localStorage и данные мира;
- не требуют Node, npm или сборщика.

Открыть пример можно напрямую как файл:

```
hangar/examples/holo-terminal/index.html
```

или с любого статического сервера из корня репозитория:

```
py -m http.server 8765
http://127.0.0.1:8765/hangar/examples/holo-terminal/index.html
```

## holo-terminal — «HOLO-9»

Вариант торгового терминала в духе голографической станции: тёмный зал,
светящаяся сетка пола, полупрозрачные панели с бирюзовым свечением.

- слева — голографический ассистент HOLO-9 с телеметрией и подсказками;
- в центре — категории, под ними две панели: «В продаже» и «На борту»;
- справа — активный корабль, крепления, трюм и системы;
- снизу — выбранный товар, покупка и док с кораблями.

Демо-взаимодействия работают локально: выбор товара, покупка, остатки,
переключение категорий, ответы ассистента, смена корабля в доке. Названия
кораблей и снаряжения взяты из `data/store.js`, чтобы макет выглядел как часть
игры, но данные здесь не читаются и не записываются.

Файлы:

- `index.html` — разметка, SVG-иконки и корабль;
- `holo.css` — палитра, стекло, свечение, сетка, адаптив;
- `holo.js` — только демо-логика интерфейса.

Макет адаптируется: на широких экранах — три колонки, на средних — корабль
уходит под рабочую область, на узких — всё складывается в одну колонку.
При нехватке высоты страница прокручивается, панели не обрезаются.
