# hangar/design — дизайн-макеты базы

Всё статичное, данные в макетах демонстрационные. Открывать через локальный сервер:
`python -m http.server 8642` → `http://127.0.0.1:8642/hangar/design/base.html`.

## Файлы

| Файл | Что это |
| --- | --- |
| `base.html` / `base.css` | первый макет: стеклянные панели поверх отдельного фона, 5 видов через `#shop`, `#ship`, `#hangar`, `#info`, `#categories` |
| `variants/v1-hud.html` | направление «промышленный HUD» (плотные панели, таблица) |
| `variants/v2-soft-glass.html` | направление «мягкое стекло» (крупные радиусы, мятный/персиковый) |
| `variants/v3-minimal.html` | направление «жёсткий минимализм» (волосяные линии, крупная типографика, лайм) |
| `variants/frames.html` | текущая структура магазина + 5 вариантов рамок, `?f=1..5` |
| `assets/station.jpg` | фон: аниме-станция, тёмные тона, 2000×1124 |
| `assets/ship.jpg` | арт корабля для hero-карточки, 2000×857 |

## Палитра и приёмы

- Фон отдельным слоем: `div.bg` (картинка) + затемнение градиентом, интерфейс поверх.
- Стекло: `background: linear-gradient(160deg, rgba(26,42,54,.78), rgba(9,17,26,.72))`,
  `backdrop-filter: blur(20px) saturate(1.3)`, внутренняя светлая кромка сверху.
- Акценты: бирюза `#8ff5e3`, персик `#ffc8a8`, лайм `#c8f45c` (только в минимализме),
  текст `#e9f2f4`, дим `#6b8086`.
- Рамки (`frames.html`): 1 — срез углов; 2 — двойной контур с уголками;
  3 — асимметричный срез; 4 — только скобки; 5 — насечки по краям.
  Реализованы через `clip-path` + `box-shadow: inset 0 0 0 1px` + фоновые градиенты.

## Баланс

Стартовые 1000 ¤ хранятся вместе с базой (`credits` в `data/store.js`, ключ `galaxy_admin_db_v1`).
Клик по блоку баланса в шапке ангара начисляет 1000 ¤ (`Store.addCredits`), продажа груза тоже пополняет баланс.
Старые базы без поля `credits` получают 1000 ¤ при загрузке.

## Цены объектов

У каждого объекта две цены: `price_buy` (покупка) и `price_sale` (продажа), читаются через
`Store.priceBuy()` / `Store.priceSale()`. В демо-наборе покупка от 351 до 1000 ¤, продажа на 150/250/350 ¤
меньше. Старое поле `price` при загрузке попадает в обе цены.

## Купленные корабли (users_ships)

`users_ships: [{ id, shipId, name, categoryId, price, boughtAt }]` — записи о купленных кораблях.
`Store.buyShip(objectId)` проверяет, что объект — корабль и хватает кредитов, списывает `price_buy`
и добавляет запись; `Store.userShips()` отдаёт список. В ангаре у выбранного корабля прячется
правый список «На корабле», у обычного объекта — снова показывается.

В демо-данных уже куплены три корабля: Гром (990 ¤, 12.10), Сокол (700 ¤, 14.10), Баржа (970 ¤, 15.10).
Все корабли стоят меньше 1000 ¤. На вкладке «Информация о базе» полоска этих кораблей
(`.user-ships`) переключает карточку: имя, категория, дата и цена покупки, свойства
(прочность/скорость/масса) и слоты с содержимым и лимитом по массе.

## Структура страницы ангара (чтобы не потерять)

Верхняя панель: логотип, статус, баланс (клик +1000 ¤). Вкладки: информация / магазин / ангар.
Под ними чипы категорий первого уровня и подкатегорий. Сетка магазина — четыре колонки равной ширины:
«Корабль» (выбранный корабль, по умолчанию первый в `users_ships`), «В продаже» (список товаров),
«На корабле» (груз), консоль сделки с кнопкой купить/продать. Если выбран корабль, колонка груза
скрывается и сетка становится из трёх колонок. Внизу — док кораблей:
квадратные карточки 156×156, выравнивание по левому краю.

Таблица объектов в админке: Название, Категория, Тип, Масса, Покупка, Продажа, Слоты,
действия; над таблицей — сортировка (по дочерней категории / названию / цене / массе).
