# Ангар: кнопка «Открыть карту» и чистый заголовок магазина

> **Статус: реализовано.** 22.10.2026.

## Цель

Убрать из шапки магазина подписи «ТОРГОВЫЙ УЗЕЛ // 04» и «Снаряжение и
снабжение», а справа от блока `HELIOS // 7 / ОРБИТАЛЬНАЯ ЗВЁЗДНАЯ БАЗА`
добавить кнопку перехода на карту «Солнечной системы».

## Изменения

- `hangar/index.html`:
  - удалить `eyebrow` «ТОРГОВЫЙ УЗЕЛ // 04» и заголовок «Снаряжение и
    снабжение»;
  - оставить строку состояния торгового терминала, выровняв её вправо;
  - добавить рядом с брендом ссылку-кнопку «Открыть карту» на
    `../space/index.html`.
- `hangar/hangar.css`:
  - стиль `.map-link` в общем стеклянно-бирюзовом стиле ангара;
  - выравнивание оставшейся строки состояния;
  - адаптив: на узких экранах кнопка не ломает шапку.
- Поднять версию `hangar.css` в `index.html`.

`hangar.js` не меняется, пересборка не нужна.

## Проверка

- В шапке магазина нет «ТОРГОВЫЙ УЗЕЛ // 04» и «Снаряжение и снабжение».
- Справа от `HELIOS // 7` видна кнопка «Открыть карту».
- Кнопка ведёт на `space/index.html`.
- На ширине 720 px и меньше шапка не переполняется.
