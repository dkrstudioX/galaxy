# demo-server — аналог Firebase для GalaxyAdminPanel

> **Статус: не реализовано.** План перенесён из `demo-server/`, кода сервера
> в репозитории нет.

## Цель

Создать легковесный real-time сервер с клиентской библиотекой, полностью заменяющий Firebase для проекта GalaxyAdminPanel. Сервер обеспечивает синхронизацию состояния между клиентами в реальном времени: позиции игроков, создание/удаление баз, покупки кораблей.

## Что заменяет

| Firebase | Аналог |
|----------|--------|
| Realtime Database / Firestore | SQLite файл на сервере |
| WebSocket push | Python WebSocket сервер |
| Auth (email/password, social) | JWT токены (email + пароль) |
| Firebase SDK | Кастомная JS библиотека в браузере |
| Cloud Functions | Нет (логика на клиенте) |

## Требования к производительности

**Цель: 200+ одновременных WebSocket подключений**

| Параметр | Значение | Обоснование |
|----------|----------|-------------|
| Одновременные подключения | 200+ | Требование проекта |
| Обновление позиции | Каждые 500 мс | Плавная анимация на клиенте |
| Время отклика сервера | < 50 мс | Непрерывная синхронизация |
| Размер БД | До 1 ГБ | Игроки + история действий |
| Память на подключение | ~50 КБ | Сессия + кэш данных |
| Общая память | ~10 МБ | 200 × 50 КБ + overhead |

**Почему SQLite выдержит:**
- 200 клиентов = ~400 операций/сек (позиции каждые 500 мс)
- SQLite выдерживает 100 000+ операций/сек на чтении
- Записи только от 200 клиентов — нагрузка минимальна
- WAL режим (Write-Ahead Logging) для параллельного чтения

## API сервера

### HTTP endpoints

**POST /api/auth/register**
- Тело: `{ "email": "user@example.com", "password": "secret123" }`
- Ответ 201: `{ "token": "jwt...", "userId": "user_xxx" }`
- Ответ 409: `{ "error": "Email уже зарегистрирован" }`
- Валидация: email формат, пароль мин 6 символов
- Хранение: bcrypt хеш пароля

**POST /api/auth/login**
- Тело: `{ "email": "user@example.com", "password": "secret123" }`
- Ответ 200: `{ "token": "jwt...", "userId": "user_xxx" }`
- Ответ 401: `{ "error": "Неверный email или пароль" }`

**GET /api/health**
- Ответ 200: `{ "status": "ok", "connected": 150 }`
- Возвращает количество активных подключений

### WebSocket события

**От клиента к серверу:**

| Событие | Тело | Описание |
|---------|------|----------|
| `join` | `{ "token": "jwt...", "name": "StarPilot", "planet": "EARTH" }` | Вход в сессию |
| `position` | `{ "phase": 0.5, "simDays": 100.0 }` | Обновление позиции |
| `action` | `{ "type": "base:create", "data": { ... } }` | Действие в мире |
| `leave` | — | Выход из сессии |

**От сервера к клиенту:**

| Событие | Тело | Описание |
|---------|------|----------|
| `players:update` | `{ "players": [ { "id", "name", "planet", "phase", "simDays" } ] }` | Полный список игроков |
| `player:joined` | `{ "id", "name", "planet" }` | Новый игрок |
| `player:moved` | `{ "id", "phase", "simDays" }` | Игрок изменил позицию |
| `player:left` | `{ "id", "name" }` | Игрок отключился |
| `world:updated` | `{ "type": "base:create", "data": { ... } }` | Изменение мира |
| `error` | `{ "code": "INVALID_TOKEN", "message": "..." }` | Ошибка |

## Модель данных SQLite

**Таблица `users`**
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | TEXT PRIMARY KEY | Уникальный ID (uuid) |
| `email` | TEXT UNIQUE | Почта пользователя |
| `password_hash` | TEXT | Bcrypt хеш |
| `created_at` | TEXT | ISO дата создания |

**Таблица `sessions`**
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | TEXT PRIMARY KEY | UUID сессии |
| `user_id` | TEXT FK | Ссылка на users |
| `name` | TEXT | Позывной |
| `planet` | TEXT | Планета входа |
| `phase` | REAL | Фаза орбиты |
| `sim_days` | REAL | Симуляционное время |
| `last_seen` | INTEGER | Timestamp последнего обновления |
| `connected` | INTEGER | 1 = онлайн, 0 = оффлайн |

**Таблица `world_changes`**
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | TEXT PRIMARY KEY | UUID |
| `user_id` | TEXT FK | Автор действия |
| `type` | TEXT | Тип: base:create, base:delete, ship:buy |
| `data` | TEXT | JSON с данными действия |
| `created_at` | TEXT | ISO дата |

## Безопасность

- **Пароли:** bcrypt хеширование (никогда plaintext)
- **JWT:** HS256, срок 24 часа, секретный ключ из config.py
- **WebSocket:** проверка токена при каждом `join`
- **Rate limiting:** 10 событий/сек на клиента
- **Валидация:** все входные данные проверяются на сервере

## Клиентская библиотека (MiniFirebase)

### API

**Класс `MiniFirebase(url)`**

| Метод | Описание |
|-------|----------|
| `connect(token, userId, name, planet)` | Подключение к серверу |
| `disconnect()` | Отключение |
| `setPosition(phase, simDays)` | Отправка позиции |
| `sendAction(type, data)` | Отправка действия |
| `on(event, callback)` | Подписка на событие |
| `off(subscriptionId)` | Отписка |

### Поведение при отключении

- Потеря связи → автопереподключение каждые 3 секунды
- Максимум 10 попыток, потом ручное переподключение
- Сервер: если нет сообщений 30 сек → сессия неактивна (`connected=0`)
- При повторном подключении сессия восстанавливается

## Развёртывание

### Локальный запуск

```powershell
cd demo-server
py -m pip install -r requirements.txt
py server.py
```

Сервер доступен по `ws://localhost:8080`

### Удалённый сервер

- Python 3.6+ (стандартный для Linux)
- `pip install websockets bcrypt`
- Запуск через systemd:
  ```ini
  [Unit]
  Description=Galaxy Multiplayer Server
  After=network.target
  
  [Service]
  ExecStart=/usr/bin/python3 /path/to/demo-server/server.py
  WorkingDirectory=/path/to/demo-server
  Restart=always
  
  [Install]
  WantedBy=multi-user.target
  ```
- HTTPS через nginx (wss:// протокол)

## Ограничения

- **Не использовать Docker** — сервер запускается напрямую через Python
- **Не использовать Node.js** — весь бэкенд на Python
- **Не использовать внешние БД** — только SQLite (один файл)
- **Не использовать внешние сервисы** — полная независимость от Google, AWS и т.д.
- **Один сервер на домен** — шардинг не требуется на первом этапе

## Нефункциональные требования

- Время отклика сервера: менее 50 мс
- Поддержка: до 200+ одновременных подключений
- Размер базы: до 1 ГБ (без деградации производительности)
- Код: только Python и JavaScript, без сборщиков, без зависимостей на стороне клиента
