# Админка: таблицы категорий на всю ширину

> **Статус: реализовано.** 22.10.2026.

## Цель

Страницы «Категории кораблей / ресурсов / оборудования» должны занимать всю
доступную ширину контента, как таблица оборудования, а не упираться в
фиксированные 1200 px.

## Изменения

- `admin/js/app.js`: класс `page-wide` включается и для страницы `categories`,
  а не только для `objects`.
- Ширина таблицы уже задана как `100%`; после снятия ограничения `#page`
  колонки растягиваются на весь контент.

## Проверка

- «Категории оборудования», «Категории кораблей» и «Категории ресурсов»
  занимают ту же ширину, что и «Оборудование».
- На узких экранах таблица по-прежнему прокручивается по горизонтали.
- Стили и поведение строк/кнопок не изменились.
