# Основное правило оформления игры (HTML/CSS)

> **Статус: реализовано.** 24.10.2026. Ветка `docs/ui-style-rule`.
> Вариант: новый канонический файл `docs/STYLE.md`; `docs/06-styles.md`
> остаётся справочником по модулям.
>
> Итог: описаны токены, типографика, сетка, стеклянная панель, строки,
> кнопки-табы (активная 1:1 с `.moon-more`), карточка объекта, поля,
> модалки, движение, запреты и чек-лист. Эталон — правая колонка `space/`.
> `AGENTS.md`, `space/ARCHITECTURE.md` и `docs/00-overview.md` ссылаются
> на новый документ.

## Цель

Зафиксировать один канонический стиль веб-интерфейса игры. Эталон — правая
колонка карты `space/`: панели «01 Солнечная система», «02 Объект»,
«03 Малые тела», карточка выбранного объекта и нижняя панель скорости
с кнопками-табами «Медленнее / Нормально / Быстрее».

Стиль был описан в двух местах и по-разному: короткий раздел в `AGENTS.md`
и общий `docs/06-styles.md` с устаревшими значениями (другие градиенты,
радиусы, палитра). Теперь есть один документ, по которому можно собрать
любой новый экран без «на глаз».

## Область действия

Только HTML/CSS-интерфейс: портал `index.html`, `admin/`, `space/`,
`hangar/`, `demo/`. Unity-проект `GalaxyHangar/` этим правилом не
регулируется. Карта `space/` — источник истины; остальные модули приводятся
к нему, а не наоборот.

## Что сделано

1. **`docs/STYLE.md`** — новый канонический документ:
   - область действия и источник истины (`space/css/style.css`);
   - характер стиля и три обязательных признака стекла;
   - токены: фон, текст, акценты, рамки, тени — с точными rgba;
   - типографика: Manrope и IBM Plex Mono, размеры и трекинг;
   - сетка: 288 px, отступы 14 px, шапка 44 px, высоты строк;
   - компонент панели: `.glass` → `.panel-block` → `.panel-head` →
     `.panel-body`, световая кромка, угловой акцент, сворачивание;
   - строки дерева и списков, выбранное состояние;
   - кнопки-табы: активная 1:1 с `.moon-more`, неактивные приглушены;
   - карточка объекта, поля, вторичные кнопки, модалки;
   - движение, запреты, чек-лист, применение к модулям.
2. **`AGENTS.md`** — основное правило вынесено в ссылку на `docs/STYLE.md`,
   краткая выжимка обновлена (табы, стекло, модалки).
3. **`space/ARCHITECTURE.md`** — ссылка на `docs/STYLE.md` вместо только
   `AGENTS.md`.
4. **`docs/00-overview.md`** — ссылка на основное правило в «Общих
   принципах».
5. **`plans/README.md`** — строка плана.

Код интерфейса не менялся: зафиксирован уже принятый визуальный язык.
Значения взяты из текущего `space/css/style.css`, а не придуманы заново.

## Критерии готовности

- В `docs/STYLE.md` есть точные значения стекла, шапки, строк, табов,
  карточки и модалок, совпадающие с `space/`.
- Активная кнопка-таб описана 1:1 с `.moon-more`; неактивная — та же
  геометрия с приглушёнными цветами.
- Явно сказано: правило только для HTML/CSS, Unity не затрагивается;
  эталон — правая колонка `space/`.
- `AGENTS.md`, `space/ARCHITECTURE.md` и `docs/00-overview.md` ссылаются
  на основной документ, старых противоречий нет.
- План отмечен **реализовано**, изменения закоммичены в отдельной ветке.
