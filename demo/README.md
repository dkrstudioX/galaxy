# Демо «Добыча астероида» — вид из кабины

Буровой корабль «Гелиос-7» догоняет астероид на его солнечной орбите,
уравнивает скорость и пристыковывается к причалу маневровыми двигателями.

Запуск: из корня репозитория `py -m http.server 8642`, страница
<http://127.0.0.1:8642/demo/>.

## Управление

| Клавиша | Действие |
|---|---|
| `W` / `S` | главный двигатель вперёд / назад |
| `A` / `D` | бортовые (маневровые) двигатели |
| мышь | поворот корабля (захват по клику), вертикаль — наклон камеры |
| `←` / `→` | поворот, резервный (без захвата мыши) |
| `H` | прожекторы |
| `U` | отстыковка |
| `Space` | автопилот (сближение → выход на орбиту → подход) |
| `1` / `2` / `3` | масштаб времени ×1 / ×2 / ×4 |
| `P`, `R`, `Esc` | пауза, сброс, отпустить мышь |

ТТХ: главный двигатель 5,8 м/с², РСУ 1,8 м/с², поворот мышью 0,0021 рад/px,
захват причала — до 1,5 м/с на дистанции 3,4 м.

## Устройство

- `js/sim.js` — модель мира без DOM и canvas. Два кадра: локальный
  (астероид идёт по прямой с постоянной скоростью — на дистанции в километры
  кривизной орбиты можно пренебречь) и гелиоцентрический для схемы орбиты
  вокруг Солнца (2,4 а.е.). Автопилот `guide()` и подсказки пилоту
  `advice()` считают одну и ту же математику: первый исполняет, второй
  зажигает стрелки на панели «Манёвр».
- `js/view.js` — вид из кабины на canvas: собственный программный 3D-рендер
  (перспектива, отсечение задних граней и ближней плоскости, художник по
  глубине). Астероиды — полигональные меши: экватор меша совпадает с 2D-формой
  из модели (причал стоит на грунте), кратеры — вмятины, рудные прожилки —
  цветные пятна руд; освещение от Солнца и прожекторов. Кабина — 3D-рама
  (стойки, раскосы, доска с корпусами прожекторов), собирается в offscreen-канву.
  Плюс звёздная сфера, пыль с ударниками, маркеры причала/дрейфа и стрелка
  на цель за кадром. Отдельной маленькой канвой рисуется схема орбиты.
- `js/app.js` — ввод (WASD, мышь через pointer lock), приборные панели,
  оверлеи, главный цикл с фиксированным шагом 1/120 с. Отладочное окно
  `window.__demo` (телепорт, стыковка, клавиши) — для автопроверки.

Стиль — общий для репозитория: тёмное стекло, Manrope + IBM Plex Mono,
акценты #75dfd2 / #aa88f6 / #bffcfc.
