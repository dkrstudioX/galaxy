# GalaxyAdminPanel — Обзор проекта

## Что это

GalaxyAdminPanel — единая игровая вселенная, состоящая из нескольких
взаимосвязанных модулей:

| Модуль | Назначение | Порт |
|--------|-----------|------|
| **Портал** (`index.html`) | Главная страница с навигацией по разделам | — |
| **Админ-панель** (`admin/`) | CRUD-редактор данных: props, slots, categories, objects | — |
| **Карта** (`space/`) | Интерактивная карта Солнечной системы (Canvas 2D) | — |
| **Ангар** (`hangar/`) | Магазин, управление кораблями, оборудование, груз | — |
| **Демо** (`demo/`) | Симулятор добычи астероидов (cockpit view, 3D) | — |
| **demo-server** | План мультиплеерного сервера (Python/SQLite/WebSocket) | — |

Все модули — часть одного продукта и используют **общий слой данных**
(`data/store.js`) и **общий стиль** (тёмная тема, стеклянные панели,
бирюзово-фиолетовые акценты).

## Общие принципы

1. **Единый стиль** — тёмный фон, стеклянные панели, Manrope + IBM Plex Mono,
   бирюзово-фиолетовые акценты. Все модули выглядят как часть одного продукта.
   Основное правило — `docs/STYLE.md`; эталон — правая колонка `space/`.

2. **Общий слой данных** — `data/store.js` используется админкой, гаром и картой.
   Данные хранятся в `localStorage` под ключом `galaxy_admin_db_v1`.

3. **Модульность** — каждый модуль (space, hangar) собирается из отдельных JS-файлов
   через `build.py` в один бандл. Зависимости между модулями определены явно.

4. **Правила мира** — `data/RULES.md` содержит договор о механиках (масса, слоты,
   трюмы, prop_2). Код подчинён правилам, а не наоборот.

## Ключевые технологии

- **Frontend**: чистый JavaScript (ES6 modules), Canvas 2D, CSS3
- **Хранение**: localStorage (клиент), план сервера — SQLite + WebSocket
- **Сборка**: Python-скрипт `build.py` — конкатенация модулей в один файл
- **Стиль**: CSS3 с backdrop-filter, градиентами, кастомными свойствами
