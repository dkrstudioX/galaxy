# Астрономические данные — `space/js/data.js`

## Обзор

Централизованный модуль с астрономическими данными: планеты, луны, малые тела.
Используется модулями `math.js`, `iso.js`, `render.js`, `smallbodies.js`,
`ui.js`, `input.js`.

## Планеты (8 штук)

Реальные орбитальные элементы эпохи J2000:

| Поле | Описание |
|------|----------|
| `a` | Большая полуось (AU) |
| `e` | Эксцентриситет |
| `l0` | Средняя аномалия при J2000 |
| `peri` | Аргумент перигелия (радианы) |
| `inc` | Наклонение (радианы) |
| `node` | Долгота восходящего узла (радианы) |
| `dist` | Расстояние для проекции (единицы мира) |
| `radius` | Радиус на карте |
| `color` | Цвет сферы |
| `ru` | Русское имя |
| `en` | Английское имя |

### Кометы — 4 штуки

| Комета | a (AU) | e | T (лет) | Особенности |
|--------|--------|---|---------|-------------|
| Галлея | 17.8 | 0.967 | 75 | Длиннопериодическая |
| Энке | 2.22 | 0.848 | 3.3 | Короткопериодическая |
| Swift-Tuttle | ~500 | 0.96 | ~133 | Из облака Оорта |
| Hale-Bopp | ~186 | 0.99 | ~2530 | Из облака Оорта |

**Отрисовка:**
- Ядро + кома + хвост строго от Солнца
- Длина хвоста: 24–72 экранных px, делится на zoom
- Длина растёт к перигелию
- Два хвоста: пылевой (изогнутый) и ионный (прямой от Солнца)

### Пояс Эджворта–Койпера

- Кольцо 800–1000 единиц от Солнца
- ~600 тусклых точек
- Периоды ~250–350 лет (закон Кеплера)
- Медленное обращение по `simDays`

### Облако Оорта

- Кольцо 1300–1800 единиц
- ~350 самых тусклых точек
- Видно на минимальном зуме (0.3x)
- Периоды миллионы лет — практически статично
- Отсекается по полудиагонали кадра

## Данные малых тел в коде

```javascript
// smallbodies.js — каждая сущность:
{
  kind: 'asteroid' | 'nea' | 'trojan' | 'comet' | 'kuiper' | 'oort',
  id: 'ceres',
  name: 'Церера',
  en: 'Ceres',
  a: 2.77,           // AU
  e: 0.08,           // эксцентриситет
  l0: 0.5,           // средняя аномалия
  peri: 0.3,         // перигелий
  inc: 0.01,         // наклонение
  node: 0.2,         // узел
  radius: 5,         // радиус на карте
  color: '#aaa',     // цвет
  small: true,       // именованное тело (hover-цель)
  system: null       // система (null для малых тел)
}
```
