# Правила мира — `data/RULES.md`

## Обзор

`data/RULES.md` — договор о механиках мира. Код приводим к правилам, а не
правила к коду. Изменение правил возможно только вместе с редактированием
этого файла.

Слой данных (`data/store.js`) общий для ангара, админки и карты.

## 1. Масса

Считаем **только массу**. Объём, энергия, охлаждение, экипаж — отложены.

### Формула

```
масса(предмет) = масса(предмет) × количество
               + Σ масса(всего, что внутри его слотов)

масса(корабль) = масса корпуса
               + Σ масса(всё, что лежит в креплениях и трюмах)
```

### Правила

- **Каждый объект учитывается ровно один раз** — на своей глубине рекурсии.
- **Ресурсы массы не имеют:** количество измеряется в **кг**, и эти кг и есть
  масса груза (1 кг ресурса = 1 кг груза).
- Груз внутри контейнера считается массой корабля, но **не занимает вместимость
  трюма** — у контейнера своя вместимость.
- Груз вне контейнера не существует. Топливо вне бака не существует.

### Реализация в `store.js`

```javascript
Store.shipMass(shipId)
// Рекурсивная масса: корпус + оборудование в слотах + груз в трюмах
// + масса груза внутри контейнеров

Store.contentsMass(shipId)
// Масса содержимого корабля (оборудование + груз)

Store.holdFree(shipId, holdIndex)
// Свободное место в трюме (масса оборудования, без учёта груза контейнеров)

Store.containerFree(shipId, entryIndex)
// Свободная вместимость контейнера

Store.massValue(obj)
// Масса одного экземпляра объекта

Store.cargoUnitsOf(shipId, mass)
// Сколько единиц объекта помещается в свободное место
```

## 2. Предметы и `prop_2`

### Типы предметов

| Тип | Как определяется | Где может лежать |
|-----|------------------|------------------|
| **Оборудование** | Всё, что не ресурс | крепление, трюм |
| **Ресурс** | Категория «Ресурсы», масса не задана | только в контейнере |
| **Контейнер** | Оборудование со свойством «Вместимость» и заполненным `prop_2` | крепление, трюм |
| **Бак** | Контейнер, у которого в `prop_2` есть топливо | крепление, трюм |

### `prop_2` — материалы

Поле объекта: материалы, с которыми предмет работает. Задаётся у:

- **Грузовых отсеков** — что хранит
- **Добывающего оборудования** — что добывает

Формат: массив имён ресурсов `["камень", "железо", "медь"]`. Пустое значение —
`0` или пустой массив `[]`.

**Правила:**
- У ресурсов `prop_2` **пусто**.
- У обычного оборудования — пусто.
- Контейнер принимает **только те ресурсы**, которые перечислены в его `prop_2`.
- Ресурс не из списка положить нельзя.

### Реализация

```javascript
// В объекте каталога:
{
  prop2: ['железо', 'медь']  // массив материалов
}

// При покупке ресурса:
Store.buyForShip(shipId, resourceId)
// Ищет первый контейнер, где prop_2 содержит resourceId
```

## 3. Крепления (слоты)

- Точка монтажа **ровно одного предмета**.
- Нет вместимости: ограничение — только тип предмета.
- Тип определяет `slotId`: `item.slotId === slot.id`. В крепление для пушек
  лазер не поставить.
- Крепления не уникальны: у корабля может быть несколько одинаковых, и в каждом —
  одинаковое оборудование.

### Реализация

```javascript
// В слоте:
{
  id: 'slot_weapon_01',
  slotId: 'weapon',  // тип крепления
  icon: 'weapon'
}

// В объекте-оборудовании:
{
  slotId: 'slot_weapon_01'  // id шаблона крепления
}
```

## 4. Трюмы (holds)

- **Точка монтажа**, а не покупной предмет.
- У корабля трюмы **фиксированные**: количество и вместимость задаются в админке.
- У каждого трюма **своя вместимость** (например, два маленьких трюма у шаттла).
- В трюм можно положить любое оборудование и контейнеры; ограничение —
  **суммарная масса оборудования не больше вместимости трюма**.
- Одинаковых предметов в трюме может быть сколько угодно (в пределах массы).
- Груз внутри контейнеров вместимость трюма не занимает.

### Реализация

```javascript
// У купленного корабля:
{
  holds: [
    { name: 'Трюм 1', capacity: 5000, contents: [entry1, entry2] },
    { name: 'Трюм 2', capacity: 3000, contents: [entry3] }
  ]
}
```

## 5. Контейнеры и баки

- Вместимость контейнера — свойство **«Вместимость»**.
- Содержимое принадлежит **конкретному контейнеру**: два одинаковых отсека на
  корабле могут хранить разное.
- Бак — тот же контейнер, у которого в `prop_2` есть топливо; топливо — ресурс.
- Контейнер можно поставить и в **крепление** («Грузовой отсек»), и в **трюм**.

### Реализация

```javascript
// Контейнер в каталоге:
{
  name: 'Грузовой отсек 2т',
  values: { massPropId: '150', capacityPropId: '2000' },
  prop2: ['железо', 'медь']
}

// Содержимое контейнера (entry):
{
  itemId: 'container_id',
  qty: '1',
  cargo: [{ itemId: 'iron_id', qty: '120' }]  // 120 кг железа
}
```

## 6. Покупка

Покупка = установка. У покупки всегда есть адрес (конкретный корабль).

### Алгоритм

```
buyForShip(recordId, objectId, qty = 1):
  1. Цена = priceBuy(object) × qty
     Если кредитов < цена → отказ «Недостаточно кредитов»

  2. Если ресурс:
     Найти первый контейнер (slots → holds), где:
       - prop_2 содержит имя ресурса
       - containerFree >= qty
     Если нет → отказ «Нет подходящего грузового отсека»
     Иначе cargo += qty (кг)

  3. Если оборудование:
     Найти свободное крепление (slotId match)
     Если есть → contents = [entry]
     Если нет → найти трюм с holdFree >= mass × qty
       Если есть → contents.push(entry)
       Если нет → отказ «Нет свободного крепления и места в трюме»

  4. Списать кредиты, сохранить
```

### Отказы

Показываются **модальным окном** с причиной.

### Следствия

- трюмы заполнены, но есть пустое крепление → купить можно;
- крепления заняты, но в трюме есть место → купить можно;
- нет ни свободного крепления, ни места в трюме → купить нельзя.

## 7. Инварианты

- Каждый объект учитывается в массе ровно один раз.
- Контейнер и бак — оборудование: их собственная масса идёт в массу оборудования,
  содержимое — отдельно, в массу груза/топлива.
- Один объект не может быть одновременно оборудованием и грузом.
- Нельзя положить ресурс в контейнер, у которого его нет в `prop_2`.
- Нельзя превысить вместимость трюма по массе оборудования.
- В крепление — только один предмет.
- У каждого купленного корабля **свой** набор оборудования (крепления, трюмы,
  содержимое).

## 8. Отложено — не реализовывать

- **Объём** и проверка `volume_ok()`.
- **Энергия, охлаждение, экипаж** (`power_ok`, `cooling_ok`, `crew_ok`).
- Поле количества при покупке ресурсов (сейчас 1 кг за нажатие).
- Крафт и добыча — отдельные этапы, не входят в покупку.

## 9. Термины

| Термин | Определение |
|--------|------------|
| **крепление** | Точка монтажа одного предмета |
| **трюм** | Точка монтажа оборудования с лимитом по массе |
| **контейнер** | Оборудование, которое хранит разрешённые ресурсы и имеет свою вместимость |
| **бак** | Контейнер для топлива |
| **содержимое** | Список «предмет + количество + (для контейнера) его груз» |
| **экземпляр** | Конкретная единица в креплении/трюме; у экземпляра-контейнера своё содержимое |
